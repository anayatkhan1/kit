This page defines the practical boundary of the first AgentCN release.

## In scope now

- A usable resale-agent flow for early users.
- Clear docs for setup, operation, and iteration.
- A stable foundation to test demand quickly.

## Out of scope for MVP

- Large enterprise feature sets.
- Heavy customization frameworks.
- Premature optimization and advanced automation layers.

## Why this scope works

Keeping scope tight helps you:

- Ship faster.
- Learn from real users earlier.
- Reduce maintenance load while fundamentals are still changing.

## Suggested phase plan

### Phase 1

- Core resale-agent behavior.
- Essential docs and onboarding.
- Baseline analytics and feedback collection.

### Phase 2

- Integration hardening.
- Better evaluation and quality checks.
- Stronger operational tooling.

### Phase 3

- Team workflows and role support.
- Scaling and reliability improvements.
- Deeper automation where it has proven ROI.

## Decision rule

If a feature does not directly improve MVP learning speed or user outcomes, defer it.
