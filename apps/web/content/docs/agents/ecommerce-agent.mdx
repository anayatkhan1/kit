## Wire your API route

Create `app/api/chat/route.ts` in your Next.js app:

```tsx showLineNumbers
import { ecommerceAgent } from "@/agents/ecommerce";
import { convertToModelMessages, type UIMessage } from "ai";

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();
  const result = ecommerceAgent(await convertToModelMessages(messages));
  return result.toUIMessageStreamResponse();
}
```

The CLI adds a `@/agents/*` path alias pointing at `./ai/agents/*` in your `tsconfig.json`.

Catalogs, maps, and schemas are written under `data/ecommerce-agent.local/`.

## API keys required

The e-commerce agent needs live Anthropic and Firecrawl API keys — there is no mock or offline fallback for store scraping.

- [ANTHROPIC_API_KEY](https://console.anthropic.com/settings/keys) — Claude model
- [FIRECRAWL_API_KEY](https://www.firecrawl.dev/app/api-keys) — map + batch scrape

### Tools

The agent exposes these tools (see `ai/agents/ecommerce/tools/toolset.ts`):

- `map_store` — discover product and category URLs on a store
- `infer_product_schema` — sample one product page and suggest commerce fields
- `extract_products` — batch-scrape product URLs with a JSON schema
- `save_catalog` — write JSON or CSV under `data/ecommerce-agent.local/catalogs`

### Default product schema

When you omit a custom schema, `extract_products` uses commerce fields: title, SKU, description, price, currency, compare-at price, stock, category, image, rating, review count, variants, and URL. Works across Shopify, WooCommerce, Magento, BigCommerce, and custom stores — same tools, any public store URL.

### Example prompts

- "Map all product URLs on `https://example-shop.com` and save the list."
- "Infer a product schema from this sample URL, then extract title, price, SKU, and stock from these 20 product links."
- "Scrape this competitor category and save a catalog JSON for price comparison."

## Extend this agent

Add your own tools without forking:

1. Create `tools/<new-tool>.ts` with `tool({ description, inputSchema, execute })`.
2. Add a zod schema in `tools/schema.ts`.
3. Register it in `tools/toolset.ts`.
4. Update `prompt.ts` so the agent knows when to call it.
5. If the tool needs new secrets, add them to the registry `envVars` (maintainers) or your `.env`.

**Example extension:** `normalize_shopify_export` — transform a saved catalog into a Shopify CSV import format. Keep scheduling/price alerts outside the agent (cron or a job runner) and call `extract_products` + `save_catalog` on each run.
